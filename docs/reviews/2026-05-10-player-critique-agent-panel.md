# 《蜉蝣哲学》挑剔玩家 Agent 群评审记录

日期：2026-05-10  
范围：`GAME-DESIGN.md`、`GAME-DESIGN-ULTIMATE.md`、`index.html`、`src/game-core.js`、`tests/game-core.test.mjs`  
方式：6 个独立评审 agent，从不同玩家类型出发，只读源码和策划案，不改文件。

## 评审团角色

| Agent 视角 | 关注问题 |
|---|---|
| 休闲手机玩家 | 5 秒内能不能开始玩，10 秒内能不能笑，首局会不会劝退 |
| 硬核 Roguelite 玩家 | 策略深度、随机公平性、构筑、跨局成长 |
| 叙事喜剧玩家 / 编剧 | 黑色幽默、真实共鸣、AI 段子味、世界观逻辑 |
| UI/UX/可访问性玩家 | 手机竖屏、信息层级、触控、动效、可访问性 |
| 中国职场社畜玩家 | 中国协作软件、绩效、加班、生活压力、真实刺痛 |
| 商业化 / 留存 / 传播玩家 | 首局留存、二局动机、收集、分享、广告/付费入口 |

## 总体判决

当前版本最严重的问题不是“没想法”，而是：

> 好玩的东西被埋在产品说明书下面；有好文本，但还不是一款能让玩家自然再开一局的游戏。

多个 agent 的共识非常强：

- 首屏不像游戏，核心选择被埋到页面下方。
- 信息密度过高，玩家还没笑先开始读仪表盘。
- 当前更像“段子按钮”，策略构筑和可复盘死亡还没成型。
- 死亡页没有变成留存枢纽，收集、图鉴、分享、遗产选择都不够显性。
- “中国打工人真实痛感”还不够，飞书/钉钉/微信群/绩效/家庭/房租等压力缺席。
- 幽默有亮点，但很多地方仍像“打工人痛点词库 + 反讽模板”。
- UI/UX 对手机玩家不友好，尤其断点、首屏、死亡页滚动和可访问性。

## 2026-05-10 自助推进记录：后果应对改造

本轮没有继续堆新卡，而是优先处理玩家已经明确抱怨的核心体验：

> 选了几次就死，因果和终局乱，看不懂，也不好玩。

已落地：

- “后果回访”到期时不再自动结算伤害，而是弹出一个玩家可操作的小决策。
- 会产生延迟后果的行动卡，在点击前直接显示“后果回访”预告。
- 每次旧账回访提供 3 种应对：
  - 硬扛：原样吃下后果，保留最直接的荒诞反噬。
  - 甩锅给流程：减半主要伤害，但损失社交，并增加被安排度。
  - 摸鱼缓冲：额外花寿命，把致命后果缓成较低伤害。
- 弹窗会显示这次旧账的风险等级，玩家能提前看到“可能致死 / 高风险 / 可承受”。
- 回合记录会写明“旧账来自哪里、玩家怎么应对、结算是否救下自己”。
- 单测覆盖：
  - 行动卡能提前预告延迟后果。
  - 到期后果能生成 3 个应对选项。
  - “摸鱼缓冲”能缓解一次原本可能致命的后果。

它解决的是“玩家没有参与感”和“后果像随机处决”的问题，但还没有解决全部“不好玩”：

- 还没有形成足够强的路线构筑。
- 首屏仍然偏仪表盘，移动端第一次选择虽然可用，但还不够爽。
- 死亡页还没变成真正的二局动机中心。
- 幽默密度仍需要从“句子好笑”进化到“流程本身荒诞”。

下一轮最优先：

1. 把首屏重排成“先选择，后仪表盘”，让玩家 3 秒内做第一件坏事。
2. 做 4 条明确路线：卷王、摸鱼、社交、搅局，每条路线有专属回访和专属死法。
3. 死亡页改成留存枢纽：新明信片、人格报告、遗产选择、下一局路线建议。

## 2026-05-10 自助推进记录：路线偏向改造

本轮处理“选项像随机段子按钮，没有构筑感”的问题。

已落地：

- 新增 4 条可读路线：
  - 卷王路线：工作 / 会议。
  - 摸鱼路线：摸鱼 / 刷手机。
  - 社交路线：社交 / 朋友圈 / 人情债。
  - 搅局路线：真话 / 误发 / 组织震荡。
- 玩家连续做 2 次同类路线选择后，主界面会出现路线面板，说明当前路线、风险和抽牌偏向。
- 抽牌系统会在路线形成后保证至少出现 1 张匹配路线的牌。
- 匹配路线的行动卡会显示“某某路线偏向牌”，让玩家知道不是纯随机。
- 修正开局保护与路线偏向冲突：普通局第 3 次选择开始就能看到路线偏向；首局仍保持简化，避免新手信息过载。

仍未解决：

- 路线目前主要影响抽牌权重，还没有每条路线的专属结局高潮。
- 路线之间缺少交叉反应，例如“卷王 + 社交”形成“朋友圈加班证明”复合路线。
- 搅局值仍然主要是数值和文本，世界可见变化还不够。

## 2026-05-10 自助推进记录：路线回访与二局建议

本轮继续处理“路线只是标签，还不够像一局故事”的问题。

已落地：

- 每条路线新增一个专属高潮旧账：
  - 卷王路线：默认负责人账单。
  - 摸鱼路线：离席审计。
  - 社交路线：人情账。
  - 搅局路线：组织免疫。
- 玩家第 3 次走同一路线时，会挂起对应路线旧账，并进入“后果回访”应对系统。
- 同一条路线旧账有去重，不会被玩家反复刷同一个高潮事件。
- 路线面板会显示“路线回访：再 N 次同路选择会挂账 / 旧账已开始排队”。
- 死亡页新增“下一世建议”：
  - 根据死因、路线、人格报告生成下一局路线建议。
  - 焦虑爆炸会建议先走摸鱼路线降噪。
  - 已形成路线的局，会建议继续追那条路线的专属旧账。
  - 显示建议优先尝试的行动牌。

验证过的关键体验：

- 连续社交 3 次后会挂起“社交路线 / 人情账”旧账。
- 下一次选择后，旧账会进入后果回访，并提供“硬扛 / 甩锅给流程 / 摸鱼缓冲”。
- 焦虑爆炸死亡页会显示“下一世建议：先给焦虑降噪”，并推荐“厕所摸鱼 / 假装写代码 / 短视频续命”。

## 2026-05-11 修改记录：后果应对去模板化

问题来自浏览器批注：后果内容很具体，但下面三个选项仍是“硬扛 / 甩锅 / 摸鱼缓冲”的通用模板，和事件语境脱钩。

已落地：

- 后果应对现在支持“事件专属按钮文案 + 通用策略效果”。
- 老板朋友圈小事不再显示模板按钮，改为：
  - 回“收到”
  - 问优先级
  - 假装离线
- 同步为其他高频旧账补了专属应对：
  - 最终版PPT复活：另存第18版 / 要一份模板 / 假装同步失败。
  - 算法回访：看续集 / 加入稍后再看 / 锁屏喝水。
  - 撤回表情包余震：认领梗图 / 甩给表情包包 / 避开茶水间。
  - 社交人情账、默认负责人、离席审计、组织免疫也有专属应对。
- 底层仍保留 `endure / deflect / slack-buffer` 三类策略，保证数值结算一致，不再为了文案破坏系统。

## 2026-05-11 修改记录：让搅局改变舞台，并打通二局入口

已落地：

- 新增“世界故障”反馈：搅局不再只是一个数值，高搅局会让主界面出现“现实偏航 / 组织现实污染 / 系统话术卡顿”的可见舞台变化。
- 世界故障文案强调玩家影响了会议纪要、流程表和组织话术，让“我在搅局”变成可感知后果，而不是进度条自嗨。
- 死亡页推荐路线从展示文案升级为二局入口：点击“带着某路线再活一次”会把推荐路线写入下一局结局追踪。
- 例：焦虑爆炸后推荐摸鱼路线，点击后下一局自动追踪“信息溺水者”，并优先出现“短视频续命”等相关选择。
- 新增测试覆盖 `buildWorldGlitches` 和 `buildRecommendedCollectionTarget`，浏览器验证了移动宽度不溢出、死亡推荐能落到下一局。

## P0 共识问题

### 1. 手机首屏看不到核心玩法

休闲玩家和 UI/UX agent 都指出：390×844 手机进入主界面后，行动卡在首屏外。玩家点了“开始搅局”，先看到 HUD、阶段、6 条属性、目标、遗产、角色、导师、反馈，最后才看到能点的卡。

劝退原因：

- 玩家第一眼不知道该点哪里。
- “荒诞选择”的爽感被仪表盘压住。
- 碎片时间玩家不会滚动研究规则。

优先改法：

- HUD 后直接放行动卡。
- 首局只显示最关键的 2-3 个状态。
- 目标、遗产、详细属性折叠到下方或抽屉。
- 移动端保证无需滚动就能完成第一次选择。

### 2. “二选一”承诺和“三选一”实现冲突

策划案强调 Reigns 式二选一，但当前实现是三选一。休闲玩家认为三选一加数值比较像考试；硬核玩家认为三选一也没有形成构筑，只是更多文本。

优先改法：

- 首局和移动端恢复二选一。
- 卡片只显示标题、短句、寿命成本、一个主后果。
- 详细数值和过程反馈在点击后展示。
- 后续可通过遗产或角色解锁“三选一”，让复杂度成为奖励。

### 3. 系统复杂，但策略不深

硬核 Roguelite agent 的批评最重：

- 策划承诺 30+ 行动卡、20+ 事件、24 张死亡明信片、商店和悟性点循环；当前核心只有 14 张行动卡、9 个事件、8 个死因。
- 抽牌主要是随机排序，不是真正的权重构筑。
- NPC 好感、连击、遗产、目标系统没有充分进入卡池和事件逻辑。
- 死亡高度可能集中在焦虑爆炸、社交清零等少数结果。

优先改法：

- 建 4 条明确路线：卷王流、摸鱼流、社交流、搅局流。
- 每条路线要有专属卡、专属事件、专属死法、专属遗产、专属风险。
- 事件从纯概率改成可读风险：玩家要知道自己为什么死。
- NPC 进入卡池：老板、小余、老王不只是数值。

### 4. 死亡页不是留存枢纽

商业化/留存 agent 指出：死亡是核心奖励，但现在死亡页只是结果展示和两个返回按钮。

缺口：

- 没有明显的 `新明信片 1/24`。
- 没有图鉴入口。
- 没有下一张未解锁剪影。
- 没有分享人格报告。
- 遗产卡自动生效，玩家没有选择权。

优先改法：

- 死亡页改成产品枢纽：
  - 新死亡明信片
  - 新人格报告
  - 新遗产卡
  - 图鉴入口
  - 分享卡入口
  - “带着这张遗产再活一次”
- 遗产卡改为开局可选装备，而不是自动套最近 3 张。

### 5. 中国职场刺痛不足

中国社畜 agent 认为当前仍偏“泛办公室”，缺少中国协作软件和生活账单夹击。

缺失高共鸣素材：

- 飞书/钉钉/企微红点
- 群里已读不回
- 周报/日报
- 请假审批
- 调休作废
- 绩效校准会
- OKR 自评
- 年终奖缩水
- HC 冻结
- 房租扣款
- 体检报告未读
- 妈妈语音 / 相亲撞加班

优先改法：

- 新增“红点压力”或“已读债”系统。
- 把 KPI 从单一事件升级成“绩效宗教”。
- 加生活线：家庭、相亲、房租、健康、婚礼份子钱。
- 反讽要更狠：拒绝加班也会死，只是死在绩效叙事里。

### 6. 幽默太急着证明自己好笑

叙事 agent 认为当前很多句子像 AI 段子，最强的是具体机制，最弱的是抽象金句。

应保留的方向：

- 默认负责人
- 会议纪要替你发言
- 老板朋友圈点赞后被私聊
- 最终版 PPT 变成 17 个最终版

应减少的方向：

- “系统”泛指太多
- “AI毒舌导师”出戏
- “表没碎，你碎了”这类陈梗
- 每张卡都固定三段式，节奏太整齐
- UI 里每个模块都抢着讲笑话

优先改法：

- 少写互联网金句，多写办公软件和人情流程如何温柔杀人。
- “系统”换成具体载体：飞书机器人、考勤机、日历邀请、报销系统、HR 自动邮件。
- 每回合只保留一个主笑点。
- 反馈形式要变化：聊天记录、系统通知、会议纪要、审批驳回、沉默。

### 7. “搅局”只是数值，没有改变世界

多个 agent 都批评标题承诺“搅局”，但玩家看到的是一根条和数字。

优先改法：

- 搅局触发可见世界变化：
  - 会议标题乱码
  - 老板话术卡顿
  - HR 发错模板
  - 群里集体沉默
  - NPC 悼念改口
  - 下一局开场被上一世污染
- “搅局+30”少显示，改成“会议纪要出现了不存在的负责人”。

### 8. UI/UX 基础问题影响体验

UI/UX agent 的 P0：

- 移动断点只有 400px，412/430px 手机可能仍三列挤爆。
- 死亡页默认可能被 `overflow:hidden` 裁掉。
- 禁止页面缩放，不利于低视力用户。
- 角色卡是 clickable div，不是 button。
- 弹窗没有 dialog 语义。
- disabled 按钮没有明显状态。
- 持续动画太多，缺少 reduced-motion。

优先改法：

- 600px 以下移动端单列或二选一卡。
- 死亡页允许滚动。
- 允许缩放。
- 角色卡改 button。
- 加 `aria-live`、焦点样式、dialog 语义。
- 加 `prefers-reduced-motion`。

## P1 问题

### 收集系统不可见

当前虽然存了 `collectedPostcards`、`collectedPersonalities`、`legacyCards`，但玩家看不到图鉴，也不知道缺什么。

改法：

- 上线图鉴页：
  - 已收集明信片
  - 未解锁黑影
  - 稀有度
  - 模糊线索
  - 推荐下一局路线

### 蜉蝣时刻没有真正实现

策划案里最后一小时应该是高潮：隐藏属性、停止搞笑、只剩人生问题。但当前只是普通阶段和一张临终卡。

改法：

- 最后一小时强制切模式。
- 隐藏大部分数值。
- 停止假通知。
- 不再抽普通卡。
- 只给 2-3 个无收益问题：
  - 飞书还在闪：回“收到”还是关机？
  - 妈妈问累不累：说“不累”还是不回？
  - 体检报告异常：点开还是先交周报？
  - 看到日落：拍朋友圈还是自己看完？

### 日落被奖励化

叙事 agent 认为“看日落 +50 搅局”破坏安静反差。日落不应该被 KPI 化。

改法：

- 日落不加分、不弹奖励、不进目标。
- 它应是放弃优化的选择。
- 如果选择日落，就暂时退出数值游戏。

### 假通知抢注意力

假通知现在像系统事件，但不能交互、不能解释，还可能盖 HUD。

改法：

- 改成“骚扰流”系统，可归档/可关闭。
- 或只在剧情节点触发。
- 与“红点压力/已读债”合并。

## P2 问题

### 分享传播未产品化

当前有 `shareText` 字段，但没有按钮、竖版图、复制文案或二维码。

改法：

- 死亡后生成 9:16 分享卡：
  - 人格大字
  - 死因
  - 最荒诞选择
  - 时间分配
  - 遗产卡
  - “你是哪种上班死法？”

### 商业化没有入口

策划写了广告和内购，但实现没有悟性点、商店、广告复活、线索广告。

建议：

- 第一阶段别卖强度，卖“继续看梗”：
  - 看广告向资本借 1 小时
  - 看广告获得一条 SSR 死法线索
  - 付费角色视角包
  - 死亡边框 / 事件包

### 长期运营结构缺失

建议：

- 每日办公室灾难
- 每周稀有死法
- 节日事件包
- 朋友圈人格分布榜

## 关键矛盾与解决方向

### 矛盾 1：休闲玩家要简单，硬核玩家要深度

解决：

- 首局前 3 回合极简：二选一、少数值、快反馈。
- 死亡后逐步解锁深度：遗产装备、图鉴线索、路线目标、NPC 风险。

### 矛盾 2：喜剧要停顿，系统想展示很多信息

解决：

- 每回合只给一个主笑点。
- 数值变化做成清楚的小结算。
- 详细过程进入因果账本，不要全部堆在主反馈区。

### 矛盾 3：日落/哲学感和 Roguelite 奖励冲突

解决：

- 日落路线不奖励分数，而奖励“停止计算”。
- 把它做成稀有反系统体验，而不是 SSR 分数卡。
