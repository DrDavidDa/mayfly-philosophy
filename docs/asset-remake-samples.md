# 《蜉蝣哲学》全量游戏资源重制样张清单

生成日期：2026-06-15

## 新美术方向

目标从“厚重黑黄手账风”升级为“轻量精品卡牌风”：

- 角色更可爱：圆润、表情夸张、状态一眼可读。
- 卡牌更清晰：图片先解释行为，文字只补充代价和反讽。
- UI 更清爽：一屏一个重点，下方行动卡是主操作。
- 场景更分明：出生、上班、摸鱼、AI捷径、社交、恋爱、账单、日落都要有独立视觉记忆点。
- 品牌更安全：不使用真实品牌名、Logo 或官方产品外观。

## 样张问题记录

- 04 整屏样张里的电脑图标略像真实品牌，正式资源必须去品牌化。
- 02 卡牌样张的卡面构图可用，但正式卡牌需要统一留白，保证中文标题和三段短标签可读。
- 03 场景样张偏精致，正式落地时需要控制文件体积，避免网页加载过慢。
- 01 早期角色尾部仍偏真实昆虫腹部，部分玩家会联想到苍蝇或不洁感，正式版不采用长腹节尾巴。
- 08 推荐作为主角基准，但所有电子设备上的符号都要改成无品牌抽象符号。

## 蜉蝣尾部舒适化规范

玩家反馈“尾巴像苍蝇、有点恶心”后，主角识别逻辑调整为：

- 蜉蝣身份由“透明翅膀 + 触角 + 短命主题”承担，不再依赖真实昆虫长腹节。
- 身体改为“圆豆/水滴/毛绒玩具”比例，尾部不尖、不长、不分节。
- 飞行时可以使用金色星光拖尾替代实体尾巴。
- 坐姿、摸鱼、疲惫状态优先用衣服、抱枕、椅背、披风遮挡后半身。
- 特殊皮肤可用叶片、斗篷、小书包、光球作为尾部轮廓，但不能像蛆、苍蝇腹部或针刺。
- 卡牌小图中尾部最多作为柔软圆形剪影出现，不能成为视觉焦点。

## 2026-06-16 落地状态

1. 主角标准形象已采用 08 的“小豆包蜉蝣”方向：圆豆身体、透明翅膀、触角识别，无长尾、无虫腹、无针刺。
2. 核心行动卡已替换为 `output/assets/card-art-*.webp` 系列，局内不再使用旧 SVG 缩略图作为正式卡面。
3. 意图页、收藏页、事件漫画和结局明信片已接入生产 WebP 资产。
4. PWA 缓存已升级到 `mayfly-v8`，包括 `mayfly-character-portrait.webp`，避免线上玩家继续看到旧角色图。
5. Phase 13 已重新规划响应式布局：手机使用自然纵向滚动，平板双列，桌面有界三列；首局目标说明不再被强行隐藏。

## 后续维护准则

1. 新增资源必须同时提供 PNG 主文件和 WebP 运行文件，并加入 `sw.js` 缓存清单。
2. 移动端禁止使用固定卡槽高度压缩行动卡，尤其不要恢复 352px/86px 这类硬编码布局。
3. 任何首局简化都只能减少噪音，不能隐藏“目标、代价、选择后果”三类核心信息。
4. 新增 AI、社交、办公梗时使用抽象名称和图形，不使用真实品牌 Logo、官方界面或商标化外观。
5. 每次 UI 大改后至少验证 371x594、390x844、768x1024、1440x900 四个视口。
