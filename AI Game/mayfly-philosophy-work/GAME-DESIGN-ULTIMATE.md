# 《蜉蝣哲学：活不过一天也要搅局》游戏策划案 v3.0

> 高概念：一只只能活 24 小时的蜉蝣，在现代办公室、社交网络和人生 KPI 中反复死亡。每一次死亡都不是失败，而是在同一天留下一个荒诞因果，让下一条生命继续收拾烂摊子。

## 0. 一句话卖点

**5 分钟活完一生，10 秒钟笑死一次，死完还能把前世留下的烂摊子传给下一只蜉蝣。**

这不是一款“努力活久一点”的游戏，而是一款“活不过一天也要把世界搅乱一点”的荒诞人生 Roguelite。

玩家每局只有 24 小时，通过二选一卡片安排工作、摸鱼、社交、恋爱、投资和思考人生。看似正确的选择会产生反作用，看似摆烂的选择可能带来顿悟。死亡后，玩家获得死亡明信片、蜉蝣人格报告和悟性点，并可跳转到同一天的另一条平行生命。前一世做过的事，会变成后一世的世界事件。

## 1. 项目定位

| 项目 | 设计 |
|---|---|
| 游戏名 | 蜉蝣哲学：活不过一天也要搅局 |
| 类型 | 荒诞人生模拟 / 卡片选择 / 轻 Roguelite / 死亡收集 |
| 平台 | HTML5 网页优先，天然适配手机分享 |
| 单局时长 | 3 到 8 分钟 |
| 目标人群 | 打工人、轻度 Roguelite 玩家、喜欢黑色幽默和人格测试的社交用户 |
| 情绪关键词 | 好笑、荒诞、扎心、上头、想截图 |
| 核心留存 | “再死一次看看还有什么离谱结局” |
| 核心传播 | “这是我的蜉蝣人格报告，你也测一下” |

## 2. 设计铁三角

### 2.1 好笑要快

玩家第一次点卡后的 10 秒内必须看到反转。不要等复杂系统铺开，第一回合就让玩家知道这游戏不正常。

示例：

玩家选择“自愿加班”，系统提示“老板很感动，于是把更多工作交给了你。恭喜，你被信任了，寿命 -6h。”

### 2.2 选择要痛

每张卡都不是简单的收益或损失，而是一个带刺的生活困境。

玩家不应该在“正确答案”和“错误答案”之间选择，而是在“两种都挺荒诞的活法”之间选择。

### 2.3 死亡要值

死亡不是结算失败，而是内容奖励。每次死亡至少给玩家三件东西：

| 奖励 | 作用 |
|---|---|
| 死亡明信片 | 视觉收集与截图传播 |
| 人格报告 | 社交分享与自我投射 |
| 因果遗产 | 影响下一条平行生命 |

## 3. v3.0 最大升级：搅局值与因果账本

原设计已经有时间、属性、死亡和收集。v3.0 要补上标题里最重要的东西：**搅局**。

### 3.1 搅局值

搅局值代表玩家对荒诞世界造成的扰动，不等于好坏，也不等于战斗力。它衡量的是：你这 24 小时有没有把这个烂系统弄出一点裂缝。

| 行为 | 搅局变化 | 解释 |
|---|---:|---|
| 当众说真话 | +20 | 破坏办公室默契 |
| 摸鱼被发现但不认错 | +15 | 制造制度尴尬 |
| 转发老板黑历史 | +30 | 引发组织震荡 |
| 完美完成任务 | -5 | 系统继续稳定运转 |
| 开会全程沉默 | -10 | 被荒诞吞没 |
| 死前看日落 | +50 | 对抗 KPI 宇宙的终极搅局 |

搅局值不直接让玩家活更久，但会决定三件事：

1. 解锁特殊死亡明信片。
2. 提高平行人生的因果联动强度。
3. 影响最终隐藏结局，是“被系统消化”，还是“让系统短暂卡顿”。

### 3.2 因果账本

每局死亡后，系统记录 1 到 3 条“前世因果”。下一局不再是完全重开，而是在同一天的另一个视角继续。

示例：

| 前世行为 | 下一世变化 |
|---|---|
| 你把 PPT 文件命名为“最终版真的最终版” | 下一世同事收到 17 个版本，会议卡权重上升 |
| 你摸鱼时误发老板表情包 | 下一世老板好感初始 -20，但搅局值 +15 |
| 你在朋友圈发“今天不想努力了” | 下一世随机事件“全公司转发你的朋友圈”加入事件池 |
| 你死于升职猝死 | 下一世出现事件“你的工位被改造成励志角” |
| 你看到了 1 秒日落 | 下一世开局焦虑 -10，并出现隐藏卡“再看一眼” |

这让“死亡即进度”不只体现在数值成长，也体现在世界记忆上。

### 3.3 荒诞反作用力

游戏有一个隐藏规则：越符合现代成功学的选择，越容易积累“荒诞债”。

| 选择倾向 | 当下收益 | 隐藏代价 |
|---|---|---|
| 持续加班 | 老板好感上升、效率上升 | 荒诞债增加，后续猝死事件权重上升 |
| 持续社交 | 社交值上升 | 黑历史复活、社死事件权重上升 |
| 持续摸鱼 | 精神恢复 | 被举报、摸鱼成仙、时间空洞事件权重上升 |
| 持续思考 | 悟性增长 | 焦虑暴涨、哲学过载事件权重上升 |
| 追求完美平衡 | 死亡风险降低 | 解锁“什么都没发生的一生”讽刺结局 |

玩家逐渐会发现，最优策略不是永远正确，而是有意识地在荒诞里制造自己的节奏。

## 4. 核心游戏循环

```text
出生
  ↓
抽取二选一卡片
  ↓
玩家选择行动
  ↓
结算时间、属性、NPC、搅局值、荒诞债
  ↓
触发随机事件或前世因果
  ↓
检查死亡
  ↓
死亡明信片 + 人格报告 + 悟性点 + 因果账本
  ↓
商店 / 图鉴 / 平行人生选择
  ↓
再来一局
```

### 4.1 单局节奏

| 阶段 | 时长 | 玩家体验 |
|---|---:|---|
| 出生与开局 | 10 秒 | “我只有 24 小时，还要上班？” |
| 选择阶段 | 2 到 5 分钟 | 二选一卡片，不断被荒诞反转 |
| 崩坏阶段 | 30 到 90 秒 | 焦虑、时间、因果开始同时压迫 |
| 蜉蝣时刻 | 20 到 40 秒 | 最后 1 小时，停止搞笑，给一点安静 |
| 死亡结算 | 30 到 60 秒 | 明信片、人格报告、悟性点、前世因果 |

### 4.2 长线循环

```text
收集死亡明信片
  解锁新卡片
    解锁新角色
      解锁新平行视角
        解锁隐藏结局
          回头补全稀有死法
```

长线不是靠堆数值，而是靠“我还没见过这个死法”“我想知道前世因果会怎么影响下一世”。

## 5. 核心系统

### 5.1 时间压缩系统

蜉蝣寿命固定为 24 小时。游戏内一张行动卡消耗 1 到 8 小时。

时间不是普通资源，而是叙事压力。玩家每点一次卡，都能感到人生少了一大块。

| 时间段 | 状态 | 视觉与内容变化 |
|---|---|---|
| 24 到 16h | 新鲜期 | 颜色明亮，卡片选择较宽松 |
| 15 到 8h | 内耗期 | 焦虑事件增多，NPC压力上升 |
| 7 到 2h | 崩坏期 | UI 抖动，假通知增多，荒诞债爆发 |
| 1h 内 | 蜉蝣时刻 | 属性隐藏，只剩人生问题卡和夕阳 |

### 5.2 四属性系统

保留原稿四属性，但让每个属性形成明确玩法性。

| 属性 | 含义 | 低值危险 | 高值危险 |
|---|---|---|---|
| 精神 | 承受荒诞的能力 | 精神崩溃 | 过度亢奋，触发“假性顿悟” |
| 社交 | 被世界看见的程度 | 查无此人 | 社交过载，黑历史复活 |
| 健康 | 身体继续运行的能力 | 身体罢工 | 健康满格会被安排更多工作 |
| 焦虑 | 现代生活噪音 | 低焦虑可触发摸鱼成仙 | 高焦虑直接爆炸 |

关键原则：属性不是越高越好。每个属性都有荒诞上限。

### 5.3 搅局值

搅局值是 v3.0 的玩家表达系统。

玩家可以选择成为卷王、摸鱼王、社交达人或哲学家，但真正稀有的路线是：如何在 24 小时里给这个荒诞系统制造一次短路。

搅局值达到不同阈值时，会出现特殊事件：

| 搅局值 | 事件 |
|---:|---|
| 30 | 同事开始讨论你“有点意思” |
| 60 | 老板开始怀疑制度是不是哪里不对 |
| 90 | 办公室出现“反 KPI 传言” |
| 120 | 时间线震荡，下一世开局出现前世遗留物 |
| 150 | 解锁隐藏结局“系统卡顿 1 秒” |

### 5.4 荒诞债

荒诞债是隐藏压力条。玩家越顺从系统，债越高；玩家越诚实或越反常，债可能下降，但会引来短期麻烦。

设计目的：

1. 打破“加班堆老板好感就是最优解”。
2. 让玩家感到现代生活的反讽。
3. 支撑黑色幽默反转。

示例事件：

| 荒诞债条件 | 触发事件 |
|---|---|
| 荒诞债 > 40 且加班连击 | 老板说“年轻人就是要多锻炼”，追加 4h 工作 |
| 荒诞债 > 60 且社交高 | 你被拉进 8 个没有用的群 |
| 荒诞债 > 80 | 系统提示“你太正常了，正常得很危险” |
| 荒诞债 = 100 | 触发死亡“被合理安排的一生” |

### 5.5 二选一卡片

每回合出现两张卡。每张卡有显性信息和隐藏反转。

```text
卡片 = 场景 + 台词 + 时间成本 + 明面效果 + 隐藏反转 + 标签 + 因果种子
```

示例卡片：

| 卡名 | 明面效果 | 隐藏反转 |
|---|---|---|
| 自愿加班 | 老板好感 +10，时间 -4h | 荒诞债 +15，后续“紧急需求”权重上升 |
| 厕所摸鱼 | 精神 +12，时间 -2h | 若摸鱼搭子好感低，触发举报 |
| 认真开会 | 社交 +8，精神 -8 | 有 20% 概率被安排写纪要 |
| 当众说真话 | 搅局 +25，老板好感 -15 | 解锁“办公室沉默 3 秒”稀有事件 |
| 给朋友圈点赞 | 社交 +5，焦虑 +5 | 可能唤醒三年前黑历史 |
| 看窗外 | 焦虑 -10，时间 -1h | 若时间 ≤ 2h，解锁“真正的日落” |

### 5.6 连击系统

连续选择同类卡触发连击。连击不是单纯奖励，而是“把一种活法推到荒诞尽头”。

| 连击 | 二连 | 三连 | 四连 |
|---|---|---|---|
| 加班 | 效率上升 | 升职幻觉 | 猝死传奇 |
| 摸鱼 | 精神恢复 | 灵魂升华 | 摸鱼成仙 |
| 社交 | 人气上升 | 黑历史摇晃 | 社交火葬场 |
| 思考 | 悟性上升 | 顿悟 | 悟了也没用 |
| 刷手机 | 快乐上升 | 信息过载 | 大脑关机 |
| 搅局 | 世界震荡 | NPC 出错 | 系统卡顿 |

### 5.7 NPC 关系网

NPC 不是背景，而是因果账本的承载者。

| NPC | 功能 | 记忆点 |
|---|---|---|
| 老板 | 压力与奖励来源 | 喜欢你时更危险，因为会给你更多事 |
| 摸鱼搭子小余 | 摸鱼路线导师 | 好感高会救你，低会举报你 |
| 卷王同事老王 | 内卷镜像 | 你越摆，他越卷；你越卷，他越像你的未来 |
| HR 小吴 | 制度拟人化 | 不判断你，只删除你 |
| 相亲对象阿晚 | 生活线入口 | 可能是上司、客户、前世债主 |
| 乌龟顾问 | 长寿旁观者 | 每次出现都慢半拍，但说话最扎心 |

NPC 好感不应该做成普通恋爱数值，而要做成荒诞关系：

老板好感越高，玩家越容易被升职猝死。

小余好感越高，玩家越可能摸鱼成功，但也更容易一起犯大事。

老王好感越低，玩家越容易被内卷碾压；好感越高，玩家可能被他拉进“共同进步地狱”。

### 5.8 平行人生系统

死亡后，玩家不是简单重开，而是选择下一个视角。

| 视角 | 寿命 | 玩法差异 |
|---|---:|---|
| 蜉蝣 | 24h | 标准体验，平衡路线 |
| 蚊子 | 12h | 高风险高搅局，摸鱼强但容易被拍死 |
| 金鱼 | 3 分钟记忆 | 会忘记上回合影响，适合荒诞喜剧 |
| 蚂蚁 | 24h | 工作效率高，但更容易被集体吞没 |
| 老王 | 24h | 内卷视角，可以看见“绩效幻觉” |
| 小余 | 24h | 摸鱼视角，可以操作隐藏路线 |
| 老板 | 24h | 管理视角，发现所有人都快死了 |

第一版可以只开放蜉蝣和蚊子，后续把平行视角作为内容扩展。

## 6. 死亡系统

### 6.1 死亡优先级

| 优先级 | 死亡类型 | 条件 |
|---:|---|---|
| 1 | 特殊剧情死 | 隐藏条件满足 |
| 2 | 焦虑爆炸 | 焦虑 ≥ 100 |
| 3 | 精神崩溃 | 精神 ≤ 0 |
| 4 | 社孤死 | 社交 ≤ 0 |
| 5 | 身体罢工 | 健康 ≤ 0 |
| 6 | 因果反噬 | 荒诞债达到阈值 |
| 7 | 寿终正寝 | 时间 ≤ 0 |

### 6.2 死亡明信片

死亡明信片是本游戏最重要的传播资产。每张明信片都应具备四个元素：

1. 一眼能懂的死法名。
2. 一句能截图传播的墓志铭。
3. 一个独特视觉构图。
4. 一个隐藏解锁条件。

示例扩展：

| 稀有度 | 死法 | 墓志铭 | 触发条件 |
|---|---|---|---|
| N | 焦虑爆炸 | 你的焦虑值爆表了。表没碎，你碎了。 | 焦虑 ≥ 100 |
| N | 查无此人 | 公司通讯录里删掉了你，没有人发现少了一行。 | 社交 ≤ 0 |
| R | 升职猝死 | 你终于拥有了 title，只是没有拥有明天。 | 老板好感 > 80 后死亡 |
| R | 社交火葬场 | 所有人都记住了你，以你最不想被记住的方式。 | 社交 > 90 且黑历史事件触发 |
| SR | 被合理安排的一生 | 你没有犯错，没有越界，也没有活过。 | 荒诞债 = 100 |
| SR | 反 KPI 先驱 | 你什么都没完成，但所有人开始怀疑 KPI。 | 搅局值 > 120 |
| SSR | 系统卡顿 1 秒 | 世界没有改变，但它停顿了一下，像是在思考。 | 搅局值 > 150 且寿终正寝 |
| SSR | 真正的日落 | 你看完了日落，没有发朋友圈。 | 蜉蝣时刻全选低欲望答案 |

### 6.3 死亡动画原则

死亡动画要短、狠、可传播。

| 时间 | 内容 |
|---:|---|
| 0 到 1 秒 | 死因标题砸下来 |
| 1 到 3 秒 | CSS 插画或漫画构图出现 |
| 3 到 6 秒 | 墓志铭逐字出现 |
| 6 到 10 秒 | 明信片定格，可截图 |

不要做长过场。玩家的爽点是“下一局马上来”。

## 7. 蜉蝣人格报告

人格报告是社交传播第二核心。

报告不只根据死因生成，而是根据选择分布、时间分配、搅局值、荒诞债、NPC 关系和蜉蝣时刻答案生成。

### 7.1 人格维度

| 维度 | 两端 |
|---|---|
| 生活姿态 | 卷生卷死 / 摸鱼成仙 |
| 世界关系 | 被系统安排 / 让系统卡顿 |
| 社交方式 | 查无此人 / 全网社死 |
| 思考深度 | 不想了 / 悟了也没用 |
| 时间观 | 每秒 KPI / 看一秒日落 |

### 7.2 人格类型

| 类型 | 判定 | 标签语 |
|---|---|---|
| 卷王蜉蝣 | 加班占比高，荒诞债高 | 你把 24 小时活成了 24 个 deadline |
| 摸鱼仙人 | 摸鱼占比高，焦虑低 | 你没赢过世界，但也没怎么输 |
| 社交烟花 | 社交高，死于社交相关事件 | 你照亮了所有人，也炸伤了自己 |
| KPI 幻觉师 | 老板好感高，搅局低 | 你以为自己在上升，其实只是被安排得更高 |
| 反制度小虫 | 搅局值高，老板好感低 | 你没有推翻世界，但你让它尴尬了一下 |
| 黄昏观察者 | 蜉蝣时刻触发日落路线 | 你终于没有优化任何东西 |
| 信息溺水者 | 刷手机高，焦虑高 | 你知道很多事，但没有一件帮你活下去 |
| 办公室幽灵 | 社交低，存在感低 | 你来过，只是系统没有刷新出来 |
| 完美无用者 | 属性均衡，搅局低 | 你什么都刚刚好，除了人生 |
| 蜉蝣哲学家 | 解锁多种人格后触发 | 你死了很多次，终于不急着证明活过 |

### 7.3 分享卡结构

```text
时间分配：
加班 25% / 摸鱼 30% / 社交 10% / 思考 20% / 搅局 15%

搅局值：132
荒诞债：44
死亡方式：系统卡顿 1 秒
墓志铭：世界没有改变，但它停顿了一下。

扫码测测你是哪种蜉蝣
```

## 8. 蜉蝣时刻

最后 1 小时不再继续普通卡片，而进入一个安静、反差强烈的模式。

屏幕从赛博办公室变成夕阳。假通知停止。属性条消失。只剩三张问题卡。

| 问题 | 选项 A | 选项 B | 影响 |
|---|---|---|---|
| 你还想证明什么？ | 证明我来过 | 不证明了 | 影响人格报告 |
| 你想把最后一小时给谁？ | 给别人看 | 给自己用 | 影响日落结局 |
| 如果重来一次呢？ | 我会更努力 | 我会看窗外 | 影响下一世因果 |

蜉蝣时刻的原则：

前面越荒诞，这里越安静。

玩家可以笑着死，但最好有一秒钟是真的停下来。

## 9. 世界观

### 9.1 世界规则

这是一个把寿命当作绩效单位的世界。

办公室里，每个人的日历不是安排时间，而是在切割生命。会议会吃掉寿命，PPT 会压缩灵魂，社交软件把存在感包装成点赞数，老板把死亡称为“阶段性成果”。

蜉蝣知道自己只能活 24 小时。荒诞的是，其他人明明能活更久，却也像只能活一天一样焦虑。

### 9.2 场景模块

| 场景 | 主题 | 代表事件 |
|---|---|---|
| 办公区 | KPI 与内卷 | 加班、会议、老板邮件、需求变更 |
| 茶水间 | 社交与八卦 | 奶茶、甩锅、同事生日、办公室传言 |
| 厕所 | 摸鱼圣地 | 假 IDE、短视频、突然敲门 |
| 电梯 | 尴尬社交 | 与老板同乘、相亲对象出现 |
| 朋友圈 | 表演型人生 | 点赞、黑历史、前任动态 |
| 天台 / 窗边 | 哲学出口 | 日落、乌龟顾问、最后 1 小时 |

## 11. 美术与 UI

### 11.1 视觉定位

**便利贴朋克 + 地狱可爱 + 崩坏办公室 UI。**

看起来像一个焦虑打工人桌面上的便签、工牌、PPT、飞书通知和死亡讣告混在一起。

### 11.2 色彩原则

| 用途 | 色彩 |
|---|---|
| 背景 | 深黑、冷灰、办公室暗蓝 |
| 幽默前景 | 便利贴黄、奶茶粉、荧光绿 |
| 危险状态 | 血红、焦虑粉、故障紫 |
| 蜉蝣时刻 | 橙、紫、深蓝夕阳 |

### 11.3 界面层级

主游戏界面应该手机优先：

1. 顶部显示剩余时间、回合、连击。
2. 中部显示四属性、搅局值、荒诞债。
3. 角色状态文案占据视觉中心。
4. 底部出现两张大卡片。
5. 假通知、前世因果、随机事件以弹层插入。

### 11.4 关键视觉资产

| 资产 | 说明 |
|---|---|
| 蜉蝣头像 | 小、焦虑、眼睛很大，适合做表情包 |
| 死亡明信片模板 | 每种死法独立配色和构图 |
| 人格报告模板 | 竖版截图，适合朋友圈和小红书 |
| 蜉蝣时刻夕阳 | 游戏情绪锚点 |
| 假通知系统 | 制造现代焦虑感 |

## 14. 商业化设计

商业化不能破坏黑色幽默，最好成为梗的一部分。

| 模式 | 设计 |
|---|---|
| 广告复活 | “看一个广告，向资本借 1 小时寿命” |

| 付费角色包 | 金鱼、乌龟、老板视角、HR 视角 |
| 死亡皮肤 | 定制墓志铭、明信片边框 |

## 16. 风险与解决方案

| 风险 | 表现 | 解决 |
|---|---|---|
| 只是段子合集 | 玩家笑一下就走 | 用搅局值、荒诞债、因果账本形成系统深度 |
| 文案太多 | 玩家不想读 | 每张卡控制在 30 字以内，反转一句话打中 |
| 随机太强 | 玩家觉得无法掌控 | 公开时间和明面效果，隐藏反转有条件可学 |
| 情绪太丧 | 玩家觉得被冒犯 | 用夸张和可爱视觉稀释痛感，蜉蝣时刻给温柔出口 |
| 内容制作压力大 | 死法和卡太多 | P0 只做少量高质量内容，后续扩展事件包 |

## 17. 首局体验脚本

### 0 到 10 秒

标题出现。

“刚出生就下班，死前才开始摸鱼。”

按钮：开始这短暂而荒诞的一天。

### 10 到 30 秒

选择角色，默认蜉蝣。

系统提示：

“你只有 24 小时。公司却给你排了 3 个会。”

### 第 1 回合

卡 A：自愿加班。

卡 B：厕所摸鱼。

如果选加班：

“老板很感动，于是把更多工作交给了你。”

如果选摸鱼：

“你在厕所里获得了短暂自由。门外有人问你是不是还活着。”

### 第 2 到 4 回合

触发随机事件、NPC 好感变化和搅局值。

玩家开始意识到：每个选择都有刺。

### 中后段

荒诞债或焦虑开始爆发。

假通知变多，UI 抖动，死亡风险抬升。

### 最后 1 小时

进入蜉蝣时刻。

问题出现：

“如果只剩一小时，你还想优化什么？”

玩家第一次感到这个游戏不只是闹。

### 死亡结算

出现死亡明信片。

出现人格报告。

出现因果账本：

“你上辈子摸鱼时误发的表情包，已经传到了老板手机里。”

按钮：

再活一次。

## 18. 这版策划相对 v2.0 的关键提升

v2.0 已经完成了“可玩”的骨架。

v3.0 要让它更像一款有灵魂、有传播力、有系统深度的游戏。

| v2.0 | v3.0 升级 |
|---|---|
| 卡片选择 | 卡片选择 + 荒诞反作用力 |
| 死亡收集 | 死亡收集 + 因果遗产 |
| 人格报告 | 人格报告 + 搅局画像 |
| Roguelite 成长 | 悟性点成长 + 世界记忆 |
| 黑色幽默 | 黑色幽默 + 最后 1 秒的温柔 |
| 活得久 | 活得有痕迹 |

## 19. 最终判断

这款游戏真正的竞争力不在“蜉蝣寿命 24 小时”这个设定本身，而在于它能把现代人的时间焦虑变成一个可笑、可玩、可分享的系统。

玩家表面上是在操控一只虫子。

实际上是在试探自己：

如果我真的只剩一天，我还会不会开这个会，改这个 PPT，发这个朋友圈，假装自己很正常？

所以最好的版本不是让玩家逃离死亡。

而是让玩家每次死亡都觉得：

“离谱，但好像也有点像我。”
