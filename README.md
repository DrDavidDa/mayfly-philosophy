你是一只只能活一天的蜉蝣。先选死前目标，再点行动看后果。一局大约三分钟。寿命用完，留下一张荒诞明信片，带着遗产再活一次。

浏览器打开就能玩。手机、电脑都行。不用安装，不用账号。

## 这一局

- **目标**：撑过几次选择。行动是卡，点下去才知道偏到哪。
- **属性**：精神、社交、健康、焦虑。哪条先崩，哪条就是死因。
- **今日挑战**：每天一题，开局就不一样。
- **死后**：荒诞明信片、人格路线、遗产卡。图鉴会记下来。

换一只命再来。短，所以值得连玩。

## 下载到本地

最快的方式是点上面的 **现在开玩**。

要把文件拿到自己机器上：

```bash
git clone https://github.com/DrDavidDa/mayfly-philosophy.git
cd "mayfly-philosophy/AI Game/mayfly-philosophy-work"
python -m http.server 8766
```

浏览器打开 `http://127.0.0.1:8766`。也可以直接双击 `index.html`。
